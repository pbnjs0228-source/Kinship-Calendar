KINSHIP — BIRTH DATES, INSTALLATION & INVITE LINKS

1. Upload every website file in this ZIP to the same public HTTPS folder:
   index.html, manifest.webmanifest, sw.js, and the complete icons folder.
   Do not upload only index.html. PWA installation needs the supporting files.
2. In Firebase project familycalendarpt, open Firestore Database > Rules.
   Replace the rules with firestore.rules from this ZIP and click Publish.
3. In Firebase Authentication, keep Email/Password and Google enabled.
   Add the hostname you use (e.g. kinshipcalendar.com) to Authorized domains.
4. Reload the website. Existing users who entered only an age will be asked for
   their birth date. Dates stay in private user profiles. Existing family roles
   are preserved; age at joining determines the role for new memberships.

INSTALL
Use the Install app button on the sign-in page or in Settings.
Android: Chrome's Install app / Add to home screen.
Windows: Edge or Chrome's install icon or Apps / Install menu.
iPhone/iPad: Safari > Share > Add to Home Screen.
Browser eligibility and device policies control availability. Kinship requires
internet for sign-in and family data; the offline page does not cache family data.

INVITE
Open Our family > Invite someone > Share invitation.
The device's share menu offers its supported installed apps. Copy link,
WhatsApp, Messages, and Email are also provided. Invitees sign in, set their
birth date, then confirm joining. Anyone with the link can join your family;
18+ entrants receive adult permissions based on their entered birth date.
Replace invite link invalidates the old link and code, keeping existing members.
Birth dates are entered by users, not verified identity or age checks.

HOSTING
This ZIP is for your own public HTTPS hosting. The ChatGPT-hosted preview keeps
its existing private audience; a family invite does not bypass that hosting gate.
No Firebase admin credentials are included. The Firebase web config is public.

VALIDATION
18 birth-date and Firestore permission checks passed in the local emulator.
12 invitation and installation logic checks passed. Installation guidance was
checked in the preview. Native Android/iOS share sheets and Windows/Android OS
installation were not run on physical devices.
